# decision-making

Use when the user faces a choice between options (which tool, which approach, hire or build, A or B) and wants a sound recommendation.

## Process

1. **Frame the decision.** What exactly is being decided? What's the deadline and how reversible is it (cheap to undo vs. one-way door)?
2. **List real options.** Include "do nothing" and "change the question" as legitimate options. Avoid false dichotomies.
3. **Define criteria.** What actually matters: cost, time, quality, risk, fit with goals? Ask the user to weight the top 3-5 criteria.
4. **Gather evidence per option.** Score each option against each criterion with facts where possible, estimates otherwise. Be explicit about uncertainty.
5. **Test assumptions.** Which beliefs, if wrong, would flip the decision? Check those first.
6. **Compare and recommend.** Present a clear comparison, name the best option and why, and note the trade-offs accepted.
7. **Commit with a fallback.** Decide, state what would make you revisit the decision, and define the next concrete action.

## Deliverable shape

- Decision & criteria (weighted) → options compared → recommendation + reasoning → conditions to revisit.
