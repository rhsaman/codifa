# pricing-page

When asked to build a pricing page:
1. Show 3 plans by default (Starter / Pro / Enterprise), highlighting the middle one as 'Most popular'.
2. Lead with the price anchor (monthly, and annual-with-discount toggle if relevant).
3. List 4-6 concrete features per plan, checked icons; never vague marketing words.
4. Add a comparison table for the key differentiating features.
5. Close with a money-back guarantee + a short FAQ addressing objections.
