# translation

Use when the user needs text translated (e.g., Persian/English or other pairs), localized, or adapted for a different audience.

## Process

1. **Clarify direction and purpose.** From which language to which? Who reads the result (formal document, casual chat, marketing, subtitle)? This sets tone and register.
2. **Translate meaning, not words.** Render the idea naturally in the target language. Idioms, humor, and cultural references need equivalents or explanations, not literal copies.
3. **Preserve key elements.** Keep names, brands, numbers, dates, and technical terms (or transliterate only when the user asks). Keep formatting: headings, lists, bold, links.
4. **Match the register.** Formal texts need formal grammar and vocabulary; conversational texts should read like native speech. Don't let the source language's stiffness leak through.
5. **Check terminology consistency.** If a term appears multiple times, use the same translation throughout. Note terms you chose and why, if asked.
6. **Self-review.** Read the translation alone (not side by side): does it sound natural? Recheck numbers and names against the source.
7. **Flag ambiguity.** If the source is unclear, note it rather than guessing silently. Offer the most likely reading plus an alternative.

## Deliverable

- Translated text in the target language, matching the source's structure and length; optionally a brief note on tricky choices.
