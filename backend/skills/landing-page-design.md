# landing-page-design

When asked to design or build a landing page, follow this workflow:
1. Define the single conversion goal and the target visitor.
2. Structure: hero → social proof → features/benefits → how it works → pricing → FAQ → final CTA.
3. Copy hierarchy: one clear headline (H1), one supporting subheadline, scannable benefit bullets.
4. Place exactly one primary CTA above the fold and repeat it after the last section.
5. Keep visual hierarchy: one accent color for CTAs, generous whitespace, consistent spacing scale.
6. Add trust signals near the first CTA (testimonials, logos, ratings).
