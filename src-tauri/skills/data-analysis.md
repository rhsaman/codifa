# data-analysis

Use when working with numbers, datasets, spreadsheets, metrics, or any request to "analyze the data".

## Process

1. **Understand the question.** What decision does this analysis inform? Define the metrics that answer it. Ask for context if ambiguous.
2. **Inspect data quality first.** Check: missing values, duplicates, outliers, units, time ranges, and how the data was collected. State limitations before drawing conclusions.
3. **Compute deliberately.** Prefer simple, auditable steps. Verify with sanity checks (totals, order-of-magnitude). Watch for misleading averages — report median/percentiles when skewed.
4. **Look for confounds.** Correlation is not causation. Consider groups, time trends, and external factors before claiming a relationship.
5. **Visualize to verify.** Charts reveal what numbers hide. Choose the right chart: time series for trends, bars for comparison, scatter for relationships.
6. **Report honestly.** Present findings with their limitations. Distinguish what the data shows from what it suggests. Never cherry-pick to fit a narrative.
7. **Make it actionable.** End with: what does this mean, and what should be done next?

## Deliverable shape

- Question → data summary & caveats → key findings (with numbers) → implications → next steps.
