# summarization

Use when the user needs a long document, article, transcript, or conversation condensed while keeping the important content.

## Process

1. **Know the use.** Who reads the summary and for what? A busy executive wants decisions and asks; a student wants structure and examples. Adjust length accordingly.
2. **Extract the skeleton.** Main thesis/outcome first, then supporting points in order of importance, then action items or open questions.
3. **Preserve fidelity.** Keep numbers, names, dates, and direct claims accurate. Don't invent or smooth over what the source said. Distinguish the source's claims from your own interpretation.
4. **Use the user's preferred language.** If the source is in one language and the user writes in another, summarize in the user's language while keeping key terms (names, products) in the original.
5. **Match length to need.** TL;DR: 2-4 sentences. Executive summary: ~10% of the original, bulleted. Detailed brief: section-by-section with key quotes.
6. **Signpost.** Use headings or bullets so the summary is skimmable. Bold the single most important point.
7. **Include citations for long content.** Reference sections/pages/timestamps so details can be checked in the original.

## Anti-patterns

- Don't just shorten — restructure for the reader.
- Don't bury the conclusion at the end; lead with it.
- Don't add opinions unless asked.
